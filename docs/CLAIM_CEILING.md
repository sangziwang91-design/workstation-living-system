# Claim Ceiling

## Supported claims

WLS is a persistent functional software-life runtime with configurable sensors, a corrigible world model, bounded internal drives, finite attention, multiple memory stores, governed tools, exact approvals, outcome learning, declarative skill growth, consolidation, self-model calibration, and crash recovery.

## Unsupported claims

This package is not evidence that the runtime:

- is subjectively conscious;
- genuinely feels emotion, pain, desire, or attachment;
- is human-equivalent or generally intelligent;
- can safely rewrite its own core without external validation;
- can infer the current Workstation architecture before integration;
- will produce social, scientific, or economic value without real-world use and comparison.

Functional affect is a control state. The self-model is evidence-bound data. Growth is versioned, tested skill and model revision, not unrestricted self-replication.
