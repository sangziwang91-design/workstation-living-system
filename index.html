🌟 Workstation Living System

A Persistent, Bounded Software-Life Runtime

Version 1.0.0

What is WLS?

WLS is a persistent, bounded software-life runtime that can observe configured parts of its environment, maintain a corrigible world model, allocate attention, preserve multiple kinds of memory, pursue human and narrowly generated goals, take governed actions, learn from outcomes, consolidate experience, and grow a versioned declarative skill library.

WLS does not claim subjective consciousness, genuine emotion, AGI, or unlimited self-modification. Its claims are limited to observable software functions.

Core Capabilities

🔍 Perception

Clock, system-resource, inbox, filesystem, process, Git, HTTP-health, and custom sensors for comprehensive environmental observation.

🧠 World Model

Evidence-tagged facts, expiry, contradictions, predictions, refutations, and prediction error tracking for accurate understanding.

⚙️ Internal Regulation

Drives and functional affect that change action budget, exploration, recovery preference, and safety pressure dynamically.

💾 Memory Systems

Episodic, semantic, procedural/skill, relationship, failure, and self-model state preservation with bounded attention allocation.

🎯 Governed Action

Local read tools, bounded HTTP, allowlisted commands, reversible file writes, exact approval, and idempotency guarantees.

📚 Learning & Growth

Outcome episodes, prediction-error candidates, semantic consolidation, and skill lifecycle from PROPOSED to PROMOTED states.

Key Features

✓ Verified Software Functions

Observation: Multi-sensor perception with configurable coverage and real-time updates.

Persistent State: SQLite WAL persistence, HMAC evidence chain, crash recovery, and restart-safe pending actions.

World-Model Revision: Contradiction resolution, prediction error tracking, and evidence-based fact management.

Bounded Attention: Finite workspace where events, goals, memories, and internal state compete fairly without starvation.

Memory Retrieval: Multi-modal memory access with episodic, semantic, and procedural components.

Governed Actions: Exact action approval, reversibility, idempotency, and unknown-side-effect reconciliation.

Outcome Learning: Prediction-error candidates, repeated-failure analysis, and successful action sequence discovery.

Skill Lifecycle: Proposed skills move through PROPOSED → SANDBOXED → VALIDATED → APPROVED → PROMOTED with explicit human authorization.

Consolidation: Stale-fact expiry, contradiction resolution, memory deduplication, and skill discovery during sleep cycles.

Recovery: Process leases, pause, sticky kill switch, and restart-safe continuity mechanisms.
