# WLS Standalone Completion Scope

## Objective

Complete the existing Workstation Living System architecture as an independently installable, continuously running, evidence-bound functional software organism.

## In scope

- stronger cognitive planning and hypothesis testing
- active perception and generic connectors
- temporal/causal world model
- long-term memory retrieval, consolidation, forgetting, and decision influence
- drives and functional affect coupled to measured outcomes
- autonomous goal generation and stopping rules
- governed external action body
- executable skill growth with sandbox, benchmark, promotion, rollback, and reuse
- evidence-updated self-model
- relationship continuity and conflict handling
- bounded developmental/evolution runtime
- long-duration reliability, recovery, performance, packaging, and tests

## Explicitly out of scope for this chain

- integration with the user's existing Workstation or five-system runtime

## Claim ceiling

The project may claim only verified software functions. It must not claim subjective consciousness, genuine emotion, AGI, or unlimited safe self-modification.

## Engineering rule

Every phase must follow READ → VERIFY → MODIFY → TEST → DELIVER. A feature is not complete until its behavior is exercised by tests and its failure path is covered.
